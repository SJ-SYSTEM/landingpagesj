## 📖 Sobre o Projeto

O Sistema de Gerenciamento de Farmácia é um projeto acadêmico desenvolvido com o objetivo de criar uma solução simples e intuitiva para auxiliar na administração de uma farmácia. O sistema busca facilitar o controle das principais atividades do estabelecimento, proporcionando maior organização, agilidade e confiabilidade nas operações diárias.

## 🎯 Objetivo

Desenvolver uma aplicação web que permita o gerenciamento das informações essenciais de uma farmácia, centralizando processos como cadastro de medicamentos, controle de estoque, registro de clientes e acompanhamento de vendas.

## ✨ Funcionalidades

* Cadastro de medicamentos;
* Consulta e edição de medicamentos cadastrados;
* Controle de estoque;
* Cadastro de clientes;
* Registro de vendas;
* Consulta do histórico de vendas;
* Organização das informações em uma interface simples e intuitiva.
