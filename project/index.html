Sistema de Gestão para Farmácia

Um sistema desenvolvido para facilitar o gerenciamento de medicamentos, clientes e vendas.

Conheça o Projeto

Sobre o Projeto

O Sistema de Gestão para Farmácia foi desenvolvido com o objetivo de modernizar e facilitar a administração de farmácias. A plataforma permite controlar medicamentos, gerenciar clientes, registrar vendas e acompanhar o estoque de maneira simples e organizada.

Funcionalidades

💊
Cadastro de Medicamentos

Registre e gerencie todos os medicamentos disponíveis na farmácia.

📦
Controle de Estoque

Acompanhe entradas e saídas de produtos em tempo real.

👥
Cadastro de Clientes

Mantenha o histórico e dados dos clientes sempre atualizados.

🛒
Registro de Vendas

Registre cada venda de forma rápida e sem erros.

📊
Relatórios de Vendas

Gere relatórios detalhados para acompanhar o desempenho.

🔐
Login de Usuários

Controle de acesso seguro para cada funcionário do sistema.

Tecnologias Utilizadas

HTML5 CSS3 JavaScript MongoDB Node.js Express

Objetivos do Sistema

  • ✔ Organizar o estoque
  • ✔ Facilitar o atendimento
  • ✔ Automatizar o registro de vendas
  • ✔ Reduzir erros de cadastro
  • ✔ Melhorar o controle administrativo
