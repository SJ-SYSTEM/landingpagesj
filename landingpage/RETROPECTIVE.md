# Retrospective - [SJ System]
**Grupo**: Gustavo Pinton, Gabriel de Camargo, Lucas Brina, Samuel Heitor 

**Tema**: Landing page do sistema desenvolvido no Projeto Interdisciplinar 

**Data:** [01/07/2026]

## 1. O que funcionou bem? 👍

 * A equipe conseguiu organizar as tarefas de forma eficiente, dividindo as responsabilidades entre pesquisa, desenvolvimento e revisão da Landing Page.
 * A comunicação entre os integrantes facilitou a definição do conteúdo e da estrutura da página.
 * O uso do Git e do GitHub permitiu acompanhar as alterações realizadas e manter o projeto organizado durante o desenvolvimento.




## 2. O que pode ser melhorado? 🔧

* Planejar melhor a distribuição das tarefas para equilibrar a carga de trabalho entre todos os integrantes.

* Realizar revisões mais frequentes durante o desenvolvimento para identificar ajustes antes da entrega.

* Dedicar mais tempo aos testes de responsividade e à validação da interface em diferentes dispositivos.



## 3. Ações de Melhoria para a próxima Sprint 🚀

| Ação | Responsável | Prazo |
|------|-------------|-------|
| Definir as tarefas e responsabilidades antes do início da Sprint. | Toda a equipe | Início da próxima Sprint |
| Realizar uma revisão do projeto antes da integração final. | Toda a equipe | Durante a Sprint |
| Executar testes de responsividade e corrigir possíveis inconsistências da interface. | Responsável pelo Front-end | Final da Sprint |

## Feedback Geral do Grupo
O desenvolvimento da Landing Page do Sistema de Gerenciamento de Farmácia contribuiu para melhorar a organização da equipe e a aplicação dos conceitos de Scrum. A divisão das atividades facilitou o andamento do projeto e o uso do GitHub auxiliou no controle das alterações realizadas. Para as próximas sprints, o grupo pretende aprimorar o planejamento, a comunicação e a etapa de testes, buscando entregas cada vez mais organizadas e com maior qualidade.
